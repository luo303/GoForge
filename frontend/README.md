# Noema Web 控制台

本目录存放 Noema 的前端代码，在 **M8** 里程碑交付（见 `../docs/plan.md`）。

## 定位

面向非命令行用户的最小控制台，覆盖三个页面：

1. 文档上传与任务列表（含进度展示与取消）
2. 任务详情（步骤明细、逐步成本、SSE 实时进度）
3. 笔记检索与导出

## 约定

- 后端优先：在 `POST /api/v1/documents` 等接口就绪前，本目录不产生业务代码。
- 页面由后端托管静态资源，不引入独立的前端服务与跨域配置。
- 技术选型在 M8 启动时确定，默认原生 HTML / JS，不预设框架与构建链。
- 联调期间一律使用 curl 验证后端接口，不以前端页面作为验收依据。
